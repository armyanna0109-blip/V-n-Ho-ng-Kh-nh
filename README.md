# Portfolio – Đỗ Hoàng Khánh Vân

Mã nguồn portfolio HTML gốc đã được đưa lên repo này. Các hình ảnh nhúng và nội dung HTML được giữ nguyên; trang chủ `index.html` ghép các phần dữ liệu trong thư mục `portfolio/` khi mở trang.

## Bật website bằng GitHub Pages

1. Mở [Settings → Pages](https://github.com/armyanna0109-blip/V-n-Ho-ng-Kh-nh/settings/pages).
2. Ở **Build and deployment**, chọn **Deploy from a branch**.
3. Chọn branch **main** và thư mục **/(root)**.
4. Nhấn **Save**.

Sau khi GitHub hoàn tất lần deploy đầu tiên, website sẽ có địa chỉ:

https://armyanna0109-blip.github.io/V-n-Ho-ng-Kh-nh/
